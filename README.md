# 2026 潮汕行程机票微信监控

为 3 名成人/学生监控 2026 年 8 月 30–31 日去程和 9 月 2–4 日返程。三人均需各 20kg 托运行李。

## 覆盖范围

- 北方出发/返程机场：宁波、杭州、上海虹桥、上海浦东、义乌、无锡、南京、温州、台州。
- 潮汕及备选机场：揭阳潮汕、梅州、厦门、泉州、广州、深圳、惠州、珠海、佛山。
- 共 45 个“出发机场 + 日期”查询任务；每 15 分钟运行 23 个任务，相邻两轮约 30 分钟完整覆盖一次。
- 每个任务会对九个目标机场逐条执行精确路线查询；使用中国市场近期搜索缓存，避免宽泛查询时冷门路线被热门目的地挤出结果集。
- 可选接入 SerpApi 的 Google Flights 独立搜索：把九个出发机场和九个到达机场合并查询，每天早晚各检查 4 个可住 3/4 晚的往返日期组合（每月1日晚间保留不查），计划任务每月最多 240 次查询，为首次启用和人工复核预留免费额度。

## 提醒规则

- 每条“出发机场—到达机场—日期”路线首次观察到的价格作为基准，不推送。
- 之后只有同时满足“刷新本路线历史最低”和“比初始基准低至少 ¥50/人”才微信提醒。
- 宁波—揭阳 2026-08-30 使用用户已知的 ¥270/人最终实付价作为基准。
- 从未出现过的新路线若第一次观察价已不高于 ¥220/人，也立即提醒。
- 使用独立的 v2 状态文件，不继承旧版任意目的地监控的去重记录。
- Google Flights 往返路线首次观察建立独立基准，之后刷新历史最低且比首次基准下降至少 ¥50/人时提醒。

## 价格边界

Travelpayouts/Aviasales Data API 是近期用户搜索缓存，不是实时库存，也不提供可靠的行李与优惠券结算信息。微信消息会附携程、去哪儿、飞猪、Google Flights、春秋官网及 Aviasales 的复核入口。付款前必须确认：

- 三名成人同一航班仍有票；
- 最终价包含税费、燃油附加费；
- 每人 20kg 托运行李；
- 学生/青年优惠和优惠券真实可用；
- 中转、退改规则与机场地面接驳成本可接受。

## 云端运行

GitHub Actions 执行查询并通过 PushPlus 发微信通知，Cloudflare Worker 每 15 分钟触发工作流。密钥只保存在 GitHub/Cloudflare Secrets 中。

Google Flights 数据源需要在 GitHub Actions 仓库 Secrets 中添加 `SERPAPI_KEY`。未配置时主监控照常运行并自动跳过该数据源。手动运行工作流并勾选 `force_google_flights`，会立即查询一次并推送当前前十往返候选。

手动初始化全部路线基线：

```powershell
python -m flight_monitor.app --initialize-baseline --scan-all
```

运行测试：

```powershell
$env:PYTHONPATH = (Resolve-Path .\src).Path
python -m unittest discover -s tests -v
```
