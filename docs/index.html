公开旅行信息项目

江浙沪低价机票观察站

关注未来 180 天内从杭州、上海和周边机场出发的国内及国际单程机票，为灵活出行者整理路线灵感和价格观察信息。

关注机场

优先：杭州杭州萧山国际机场（HGH）
其次：上海浦东（PVG）与虹桥（SHA）
周边补充宁波、义乌、南京、温州、无锡、台州

我们的筛选原则

重点观察单程、经济舱和低含税总价；发现候选价格后，会再次核对两名成人的实时含税价格与座位情况。行李额度以最终预订页面展示为准。

票价和座位随时变化，本项目只提供信息参考，不销售机票，也不保证任何价格持续有效。实际行程、退改规则和支付金额应以航空公司或预订平台为准。

旅行提示

比较邻近机场高铁可达的周边机场有时能显著降低票价。
核对附加费用留意税费、托运行李和支付服务费。
确认证件与签证国际行程下单前检查护照、签证及入境要求。
